# Security Policy

## Scope

This repository is primarily a collection of public documentation, source links,
structured observations, and derived tables. Please report suspected security
issues in the repository, its automation, or its contribution workflow rather
than publishing details in a public issue.

## Reporting a vulnerability

While the repository remains under Amadeus stewardship, report vulnerabilities
privately to `opensource@amadeus.com`. Include:

- a concise description and affected path or workflow;
- reproduction steps or a minimal proof of concept, where safe;
- the potential impact; and
- any suggested mitigation.

Do not include confidential data that is not necessary to investigate the report.

## Response

The maintainers will acknowledge and assess reports as promptly as practical and
will coordinate disclosure of confirmed issues with the reporter.

**Before any transfer to the Green Software Foundation, the receiving project
owners must confirm the reporting channel, response commitments, and whether
GitHub private vulnerability reporting will be enabled.**
